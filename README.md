# 🐍 Snake Water Gun Game

A simple **Snake 🐍, Water 💧, Gun 🔫** game made in Python.

📄 **Source Code:** [`s-w-g-v2.py`](s-w-g-v2.py)

The game is played for **5 rounds** against the computer. The computer randomly chooses its move, and the winner of each round is decided using a lookup table. At the end, the final scores are compared to declare the overall winner.

## ✨ Features

- 🎲 Random computer moves
- 🎮 5-round gameplay
- ✅ Input validation
- 📊 Score tracking
- 🏆 Final winner announcement

## 🚀 How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Run the program:

```bash
python s-w-g-v2.py
```

## 🎮 Controls

| Input | Move |
|------:|------|
| `1` | 🐍 Snake |
| `2` | 💧 Water |
| `3` | 🔫 Gun |

Enter the number corresponding to your move when prompted.

## 📷 Example

```text
1. Snake
2. Water
3. Gun
Choose Your Move:
1 or 2 or 3

> 3

Your move is Gun
Computer move is Snake
You win
```

## 📚 Concepts Used

- Functions
- Lists
- 2D Lists (Lookup Table)
- Dictionaries
- `random.choice()`
- Loops
- Input Validation (`try`/`except`)
- Score Keeping

## 📜 Rules

- Snake 🐍 drinks Water 💧
- Water 💧 douses Gun 🔫
- Gun 🔫 kills Snake 🐍
- Same moves result in a Draw 🤝
